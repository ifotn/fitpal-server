# Lesson 4: REST API Part 1

Setting up a local Express.js REST API with in-memory data

## NPM Commands

```npm i express typescript``` - runtime dependencies

```npm i @types/node ts-node @types/express --save-dev``` - dev dependencies

```npm i body-parser``` - required to read http request body for POST and PUT methods (create and update)

### Lesson 5 Commands

```npm i mongoose``` - data access lib for MongoDB

### Lesson 6 Commands

```npm i swagger-jsdoc swagger-ui-express``` - swagger for runtime api doc serving

```npm i @types/swagger-jsdoc @types/swagger-ui-express --save-dev``` - swagger for dev
